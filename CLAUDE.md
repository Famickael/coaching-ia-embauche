# Instructions Claude Code

Lire `README.md`, en particulier les sections « Règles de conception à respecter », « Passage en production » et « Reprise du travail avec Claude Code », avant toute modification.

- Vérifier chaque changement avec `npm run build`, `npm run test:analysis` et, si l’environnement le permet, `npm run test:e2e`.
- Ne jamais introduire de note, de score ni d’inférence émotionnelle (voir `src/lib/analysis.js`, `isCompliant`).
- Textes d’interface en français, sans tiret cadratin.
